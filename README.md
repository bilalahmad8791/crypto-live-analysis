# 📊 Live Cryptocurrency Data Fetching & Analysis

This project fetches live data for the **top 50 cryptocurrencies** using the **CoinGecko API**. It performs real-time data analysis, updates an **Excel sheet every 5 minutes**, and generates a **detailed analysis report (PDF & TXT).**  

## 🚀 Features
- ✅ Fetches real-time cryptocurrency data (Name, Symbol, Price, Market Cap, etc.)
- ✅ Identifies **Top 5 Cryptocurrencies by Market Cap**
- ✅ Calculates **Average Price of Top 50 Cryptocurrencies**
- ✅ Finds **Highest & Lowest 24-hour Percentage Price Change**
- ✅ **Auto-Updates** an Excel sheet (`crypto_data.xlsx`) every **5 minutes**
- ✅ Generates **PDF & TXT reports** of the analysis

---

## 👅 Installation
1️⃣ **Install Python** (if not installed) ➡ [Download Python](https://www.python.org/downloads/)  
2️⃣ **Install required libraries** using the following command:
   ```bash
   pip install requests pandas openpyxl fpdf
   ```

---

## ⚡ Running the Script
To start fetching live data and updating the Excel sheet, run:
   ```bash
   python crypto_analysis.py
   ```
- The script will **fetch new data every 5 minutes**.
- The **Excel file (`crypto_data.xlsx`)** will update automatically.
