# Live Cryptocurrency Data Fetching & Analysis

This project fetches live data of the top 50 cryptocurrencies using the CoinGecko API. It performs data analysis and updates an Excel sheet every 5 minutes with the latest prices, market cap, and percentage changes.
- Fetches real-time cryptocurrency data
- Identifies the top 5 cryptocurrencies by market capitalization
- Calculates the average price of the top 50 cryptocurrencies
- Finds the highest and lowest 24-hour percentage price change
- Automatically updates an Excel sheet every 5 minutes
- Generates an analysis report (PDF & TXT)
